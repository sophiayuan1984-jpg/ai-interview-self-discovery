# AI 面试官 & 自我探索（ai-interview-self-discovery）

装上之后，和 AI 聊天就像在被一位**会追问、要证据、不吹捧**的面试官面试。
同一套访谈引擎，两种模式（自我探索分两类）：

| 模式 | 你说 | 你得到 |
|---|---|---|
| **模拟面试** | “按这个 JD 面试我” / “模拟一场产品经理面试” | 逐题提问 + 追问 → 岗位要求 × 证据状态表、最强案例、证据缺口、表达反馈、≤3 项准备行动 |
| **自我探索 · 岗位适配** | “我适合做 XX 岗位吗” / “A 和 B 两个岗位哪个更适合我” | 拆解岗位真实工作与代价 → 能力 / 动机与能量 / 工作方式与环境 / 价值与代价 四层适配状态、优势与差距、验证实验 |
| **自我探索 · 方向探索** | “我接下来的工作方向该往哪走” / “我要不要换个方向” | 从真实经历提炼有劲的任务类型、合适的环境、不愿付出的代价 → 1–3 个候选方向（附依据与待验证假设）、验证实验 |

模拟面试回答“能不能向面试官证明我能胜任”；自我探索还回答“我想不想做、做起来是否有劲、能不能接受它的代价”。一次会话只运行一种模式，中途可以切换。

它不是一张问题清单：每轮只问一个问题，问什么取决于你上一句说了什么；“我有战略思维”这类说法只会换来一句“举个具体例子？”。

## 一句话安装 / 更新

**同一条命令，第一次执行是安装，之后再执行就是更新。**

macOS / Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/__REPO__/main/install.sh | bash
```

Windows（PowerShell）：

```powershell
irm https://raw.githubusercontent.com/__REPO__/main/install.ps1 | iex
```

或者直接对你的 AI 助手说一句：

> 帮我安装这个 skill：https://github.com/__REPO__

脚本会自动检测本机已有的 Agent（WorkBuddy / CodeBuddy / Claude Code / Codex / Cursor），装到各自的 `skills/` 目录，并显示 `已安装 v1.0.0` 或 `已更新 v1.0.0 → v1.1.0`。

## 怎么用

新开一个对话，随便说一句：

- “面试我，岗位是 B 端产品经理，3–5 年经验” —— 没有 JD 也能开始
- “按这个 JD 面试我，用教练模式”（然后粘贴 JD）—— 每题后给 1–2 句点评；默认是实战模式，结束后统一反馈
- “我想看看自己适不适合做 XX 岗位”
- “A 和 B 两个岗位，帮我看看哪个更适合我”
- “我接下来的工作方向该往哪走”

过程中随时可以说：**跳过 / 换个话题 / 看档案 / 你理解错了 / 切换到自我探索 / 出报告**。
信息很少就要报告时，会给你一份标明证据边界的「初步报告」，而不是编一份完整画像。

## 做一个「了解你自己」的版本

**零改动**：Skill 里没有任何预设的个人信息，所有理解都只来自对话。任何人装上就能用“自我探索”模式看清自己适不适合某个岗位、接下来往哪个方向走。

**想保留下来、下次接着聊**：报告生成后，AI 会问是否存成本地 Markdown（只有你同意才写）。下次把这个文件发给 AI，它会从“待了解事项”继续。

**想定制成自己的版本**（换维度、加岗位族、改报告结构）：

1. 在 GitHub 上 fork 本仓库（或新建一个空的公开仓库，把文件放进去）
2. 修改 `references/` 里的框架或模板（核心机制在 `SKILL.md`，一般不用动）
3. 执行一行：
   ```bash
   bash scripts/publish.sh 你的GitHub用户名/仓库名 1.0.0
   ```
   它会把安装命令里的仓库地址改成你的、提交并推送，最后打印出**属于你的一句话安装命令**。以后改完再执行一次（带新版本号），别人重跑安装命令就会更新。

## 边界

- 不是心理咨询或测评，不做诊断、不给人格类型。
- 不打分、不给录用概率；“尚未验证”不等于“不具备”。
- 报告只基于你在对话中说的内容，AI 不会核实履历。
- 默认不跨会话保存任何信息。
- **默认不读取平台记忆**：两种模式的题目、追问和报告都只基于你本次说的内容。如果你希望 AI 参考它对你的了解，主动说一句“可以参考你对我的了解”——记忆也只会用来提议从哪个话题聊起，不会当作证据；说“别用记忆”即可撤回。
- 请匿名化公司、人名和内部项目；不要提供证件号、账号等敏感信息。

# 报告模板

按模式选用模板：模拟面试 → A；自我探索 → B1（岗位适配）或 B2（方向探索）。用户中途结束时，在标题上标注「初步报告」，并在开头写清证据范围。

---

## 证据标签（所有报告通用）

| 标签 | 含义 |
|---|---|
| 【用户陈述】 | 用户明确说过，但未独立核实 |
| 【案例支持】 | 用户提供的具体经历支持该判断 |
| 【重复模式】 | 两个及以上例子出现相似的行为或决策模式 |
| 【暂定假设】 | 合理，但仍需用户确认或更多证据 |
| 【尚未了解】 | 本次访谈没有建立相关事实 |
| 【反例 / 限制】 | 使结论不确定或缩小适用范围的信息 |
| 【用户已确认】 / 【用户已修正】 | 在核对环节由用户确认或修改过 |

## 模板 A：模拟面试报告

```markdown
# 模拟面试反馈｜{岗位}（{职级}）
> 访谈范围：{N} 个主问题，覆盖 {维度列表}；JD：{有/无}；反馈方式：{实战/教练}
> 本报告仅基于你在本次对话中的陈述，未核实履历。

## 1. 整体总结
{3–5 句，只写有证据支持的判断；每句后标证据标签}

## 2. 岗位要求 × 证据状态
| 岗位要求 | 必须/加分 | 证据状态 | 依据（对话中的案例） | 还缺什么 |
|---|---|---|---|---|
| … | 必须 | 有证据支持 / 部分支持 / 尚未验证 / 潜在差距 | … | … |

## 3. 最有说服力的案例
**{案例名}**：{1–2 句概括}
- 为什么有说服力：{个人行动清楚 / 有取舍 / 结果可衡量 …}
- 可以讲得更好的地方：{…}

## 4. 潜在疑虑与证据缺口
- {面试官可能追问的地方 + 原因}

## 5. 表达方式反馈
| 方面 | 观察 | 建议 |
|---|---|---|
| 结构（是否先说结论） | … | … |
| 长度与节奏 | … | … |
| 具体程度 | … | … |

## 6. 优先准备行动（最多 3 项）
1. {具体、可执行，如“为‘结果衡量’准备一个有基线数据的案例”}

## 7. 评估依据与局限
- 依据：{哪些回答}
- 局限：{未覆盖的维度、用户跳过的问题、无法核实的信息}
- 本反馈不代表任何公司的真实评价，也不预测录用结果。
```

## 模板 B1：岗位适配报告（自我探索 · 岗位适配）

```markdown
# 岗位适配报告｜{目标岗位}（{组织类型 / 职级}）
> 本次覆盖：{讨论过的经历数量}；岗位信息来源：{用户描述 / JD / 一般性信息}
> 这是一组基于你分享内容的可讨论判断，不是测评，也不替你做决定。

## 1. 你想弄清的问题与本次范围
{用户最初的问题；聊到了哪些、没聊到哪些}

## 2. 这个岗位实际在做什么
| 核心任务 / 典型代价 | 来源 | 你对它的了解程度 |
|---|---|---|
| … | 用户描述 / JD / 【一般性信息，需核实】 | 清楚 / 部分了解 / 基本不了解 |

## 3. 四个层面的适配情况
| 层面 | 适配状态 | 依据（对话中的经历） | 反例 / 限制 |
|---|---|---|---|
| 能力 | 有匹配证据 / 部分匹配 / 尚未了解 / 可能不匹配 | … | … |
| 动机与能量 | … | … | … |
| 工作方式与环境 | … | … | … |
| 价值与代价 | … | … | … |

## 4. 整体判断
目前证据倾向于：{一句话，确定程度与证据强度匹配}
最关键的未知：{一项}

## 5. 你的优势与差距（对这个岗位而言）
- 可迁移的优势：{…}【案例支持 / 重复模式】
- 需要补的差距：{…}【用户陈述 / 案例支持】

## 6. 偏好、选择与动机
- 你明确表达的：{…}【用户陈述】
- 你实际做出的选择显示：{…}【案例支持】
- 仍待验证的解释：{…}【暂定假设】

## 7. 验证实验（1–3 项，小规模、可逆）
| 要检验的假设 | 实验 | 时长 | 观察什么 |
|---|---|---|---|

## 8. 你的确认与修正
- 你确认了：{…}
- 你修正了：{原解释 → 你的版本}

## 9. 证据边界
{基于几个经历；哪些层面证据单一；岗位信息哪些未经核实}
```

多岗位比较时，第 3 节改为“层面 × 岗位”对比表（每格写状态 + 依据），第 4 节写“差异最大的层面”和“最需要验证的一点”，不给总分。

## 初步报告（用户提前结束时）

- 标题加「初步报告」。
- 开头写：“本次只聊了 {N} 轮，以下判断证据有限。”
- **篇幅与信息量匹配**：聊了不到 5 轮时，不套完整模板，改用下面的精简结构（约 10–15 行）；不要为了显得完整而逐章填写“尚未了解”，**更不要用推断填满**。
- 末尾列出最重要的 2–3 个未知项，作为下次继续的入口。

精简结构：

```markdown
# {模拟面试反馈 / 岗位适配报告 / 方向探索报告}｜{岗位或问题}「初步报告」
> 本次只聊了 {N} 轮，以下判断证据有限；仅基于你的陈述，未核实。

**目前知道的**
- {要点}【证据标签】

**目前最不确定的**（下次可以从这里继续）
1. {未知项}
2. {未知项}

**现在就能做的一件事**
- {一项最具体的准备或小实验}
```

## 输出前自检

- [ ] 报告回应了用户最初的目标
- [ ] 每个核心判断都能指回对话中的具体内容
- [ ] 没有把用户陈述写成被验证的事实
- [ ] 没有任何内容来自平台记忆；若用户同意参考记忆选话题，已在证据边界中注明
- [ ] 没有分数、百分比、录用概率、人格类型、总体适配分
- [ ] 没有替用户做决定（如“你应该转行”）；未核实的岗位/行业信息已标注
- [ ] 没有空泛赞美（“你非常优秀”“潜力巨大”）
- [ ] 确定程度与证据强度匹配；单一事件没有被写成稳定特质
- [ ] 用户在核对环节的修正已经体现
- [ ] 写明了局限；提前结束时已标为“初步报告”

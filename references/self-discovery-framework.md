# 自我探索框架（职业向）

目标：基于**真实经历**，帮用户回答两类问题之一，并形成可确认、可修订的判断——而不是一份听起来很准的性格标签。

| 探索类型 | 用户的问题（通用说法） | 产出 |
|---|---|---|
| **岗位适配** | “我适合做 XX 岗位吗？”“A 和 B 两个岗位，哪个更适合我？”“要不要从现在的岗位转到 XX？” | 岗位适配报告 |
| **方向探索** | “我接下来的工作方向该往哪走？”“我要不要换个方向？”“我适合做什么样的工作？” | 方向探索报告 |

**与模拟面试的区别**：模拟面试只回答“能不能向面试官证明我能胜任”；自我探索还要回答“我想不想做、做起来是否有劲、能不能接受这份工作的方式与代价”。能力够但做着耗竭、或能力暂时不够但很来劲，都是自我探索要看清的情况。

> **记忆隔离**：探索的话题、追问和候选方向只来自用户本次的讲述，不根据平台记忆推断用户的行业、经历、偏好或现实约束。用户明确同意参考记忆时，也只能用来提议从哪个话题开始，不能当作适配或方向判断的证据（见 SKILL.md 规则 10）。

用户提到具体岗位 → 岗位适配；没有具体岗位、或候选方向超过 3 个 → 方向探索。不确定时问一句：“你心里已经有想去的岗位了吗，还是想先看看方向？”

---

## 1. 四个层面 + 现实约束

两种探索类型都用同一组层面取证、同一组层面出结论。

| 层面 | 要回答的问题 | 主要证据来源 |
|---|---|---|
| **能力** | 这类工作的核心任务，你做过吗、做得怎样？差距在哪？ | 做过的类似任务、可迁移的经历、结果 |
| **动机与能量** | 你为什么想做？做这类事时是更有劲还是更消耗？ | 做完后的能量感、主动投入的程度、持续了多久 |
| **工作方式与环境** | 这份工作的节奏、协作方式、确定性、对内 / 对外，与你实际表现好的环境是否一致？ | 高峰 / 低谷经历中的环境条件 |
| **价值与代价** | 你最看重什么？这份工作的典型代价（如加班、出差、业绩压力、收入波动、频繁对外沟通）你能接受吗？ | 过去遇到类似代价时的实际选择，而不只是口头态度 |

**现实约束**（作为背景，不作评判）：时间窗口、收入底线、城市、家庭安排、资质门槛等。只记录用户愿意说的，不追问细节。

## 2. 岗位适配流程

1. **明确目标岗位**：岗位名称、组织类型、职级；问一句用户了解到的这个岗位**日常主要在做什么**。
   - 关键：区分“想象中的岗位”和“真实的工作内容”。很多不适配来自对岗位的误解。
   - 用户了解很少时，AI 可以概括该类岗位的典型工作内容，但必须标注【一般性信息，不代表具体公司】，并在报告中建议去核实。
2. **拆解岗位**：列出 3–5 项核心任务 + 2–3 项典型代价，用一行请用户确认或修改（同面试模式的 JD 提取）。用户有 JD 时直接从 JD 拆。
3. **逐项取证**（每轮一问，按信息缺口挑选）：
   - 核心任务 → “你做过最接近这件事的经历是什么？”（能力）→ 下一轮再问“做那件事的时候，你是越做越有劲，还是在硬撑？”（能量）
   - 典型代价 → “以前遇到类似的情况（如连续加班 / 频繁出差 / 背业绩指标），你实际是怎么处理的？”（价值与代价）
   - 动机 → “这个岗位吸引你的具体是哪一点？”——动机若只来自光环、薪资或逃离现状，不评判，只记录并继续追问。
   - **节奏**：能力层不追求面试级的细节，够判断“做过没有、做得怎样、个人贡献大致多少”即可——同一个案例能力追问最多 2 次，下一问就转到这个案例的**能量感**或它暴露的**代价**，再换下一项核心任务。否则会变成第二个模拟面试。
4. **找反例与差距**：“有没有做类似事情、但感觉很差的时候？”“哪项核心任务你几乎没做过？”
5. **形成适配判断**：按四个层面逐项标注状态（见下表），给出“目前证据倾向于……，最关键的未知是……”的整体表述。**不打分，不替用户做决定。**
6. **设计验证实验**：针对最关键的未知项，见第 7 节。

**多岗位比较**：用同一组层面做对比表，每格写证据和状态，不给总分；最后指出“两者差异最大的层面”和“最需要验证的一点”。

### 适配状态

| 状态 | 判定 |
|---|---|
| **有匹配证据** | 有具体经历支持该层面与岗位要求一致 |
| **部分匹配** | 有相关经历，但情境差异大、证据单一，或用户感受矛盾 |
| **尚未了解** | 本次没有获得足够信息——不等于不适合 |
| **可能不匹配** | 有具体经历显示该层面与岗位要求冲突（如多次在类似代价下明显耗竭），需用户确认 |

## 3. 方向探索流程

1. **触发原因**：“是什么让你现在开始想这个问题？”——不满意现状、主动规划、外部变化（组织调整、行业变化等），会决定探索的重点。
2. **现实约束**：问一次用户愿意分享的约束（时间窗口、收入底线等），之后不再追问。
3. **取材**：用第 5 节的技巧收集 2–3 个具体经历，重点是高峰 / 低谷对比和“实际选择 vs 声称偏好”。
4. **归纳**：从经历中提炼三样东西，并请用户确认：
   - 让你有劲的**任务类型**（如“把混乱的信息理清”“面对面说服别人”“把一件事做到很精细”）
   - 你表现好的**环境条件**（如“目标清楚但方法自主”“小团队、反馈快”）
   - 你**不愿意再付出的代价**
5. **生成 1–3 个候选方向**：具体到岗位族或工作形态（如“偏研究分析类岗位”“对外拓展类工作”“在现岗位内转向更偏某类任务的职责”）。每个方向附：依据哪些经历、匹配哪几个层面、最关键的待验证假设。
   - 候选方向可以包括“留在当前方向但调整职责”。
   - AI 可以提出用户没提到的方向，但必须标为【暂定假设】并说明依据；用户否定就删掉。
6. **设计验证实验**：每个候选方向配一个低成本验证方式。

## 4. 取证问题库（按层面，按语境改写，不要照念；每轮只用一个）

### 能力
- “这类工作里最核心的一件事，你做过最接近的是哪一次？”
- “那次结果怎样，你是怎么判断做得好不好的？”
- “哪项核心任务是你目前几乎没有经验的？”

### 动机与能量
- “最近一个月，哪件工作做完你反而更有劲？”
- “有没有哪件事，没人要求你也主动做了很久？”
- “这个岗位 / 方向吸引你的具体是哪一点？”

### 工作方式与环境
- “你状态最好的一段工作时期，当时的环境是什么样的？”
- “哪段时间你觉得自己没发挥出来？”
- “你更习惯一个人钻研，还是频繁和人协作推进？”

### 价值与代价
- “讲一次你必须在两件都重要的东西之间做选择的时候，你最后选了什么？”
- “以前遇到类似的代价（如长期加班 / 频繁出差 / 背指标），你实际是怎么处理的？”
- “如果这份工作在某方面需要你让步，你的底线在哪？”

## 5. 取材技巧

| 技巧 | 做法 | 用途 |
|---|---|---|
| 高峰 / 低谷对比 | 各要一个具体工作事件，比较两者的条件差异 | 找出你表现好的环境与任务类型 |
| 说的 vs 做的 | 把“我看重 X”和“上次你实际选了 Y”放在一起问 | 区分声称偏好和实际选择 |
| 能量记账 | 问“做完之后更有劲还是更累” | 区分“擅长”与“想做” |
| 岗位现实核对 | “你了解到这个岗位一周里大部分时间在做什么？” | 区分想象中的岗位与真实工作 |
| 第三方视角 | “同事或上级通常会因为什么事找你？” | 补充视角（仍属用户陈述，不是外部证据） |
| 反例搜索 | “有没有做类似的事、但感觉完全不同的时候？” | 检验判断是否稳定、缩小适用范围 |
| 具体化 | “最近一次是什么时候？” | 把泛泛的“总是”“从来”落到具体事件 |

## 6. 形成和呈现假设

- **单个案例**只能形成“暂定观察”；**两个及以上**相似案例才可以称为“重复模式”。
- 呈现格式：

> 在【情境】中，你似乎【行为 / 感受】，这可能意味着你在【层面】上与【岗位 / 方向】【匹配 / 存在冲突】。
> 依据：【案例 A、案例 B】。
> 也可能是：【另一种解释，如当时的团队、上级、阶段性压力】。
> 这个判断符合你的感受吗？

- 用户否定时：记为“用户修正”，问一句“你觉得更准确的说法是什么？”，然后按用户的版本更新。不坚持原解释。

### 三类信息分开记录

| 类别 | 例子 | 报告中如何呈现 |
|---|---|---|
| 陈述的偏好 / 价值 | “我很看重自由” | 用户陈述 |
| 实际做出的选择 | “上次为了稳定留在了原岗位” | 案例支持 |
| AI 推测的动机 | “可能在不确定时更优先安全感” | 暂定假设，附其他解释 |

三者不一致时不是“问题”，而是有价值的探索点——先问情境差异，例如：“你前面说很看重自由，刚才的例子里你选了更稳定的那个，这两次的情境有什么不同吗？”

## 7. 验证实验

报告中给出 1–3 个**小规模、可逆、可观察**的实验，用来检验最关键的未知项，而不是“人生建议”。

| 实验类型 | 适合检验 | 例子 |
|---|---|---|
| 信息访谈 | 岗位真实内容、代价 | 约 2 位该岗位从业者各聊 30 分钟，问“一周时间怎么分配”“最难受的部分是什么” |
| 试做典型任务 | 能力 + 能量 | 按该岗位的一项典型任务做一个小作品，记录做完后的能量感 |
| 内部尝试 | 工作方式与环境 | 在现岗位主动承担一项接近目标岗位的工作，持续 2–4 周 |
| 短期参与 | 动机是否持续 | 项目制合作、兼职、志愿参与 |

格式：

| 要检验的假设 | 实验 | 时长 | 观察什么 |
|---|---|---|---|
| 你在“理清模糊问题”时最有能量 | 主动认领一个模糊需求的梳理工作 | 1–2 周 | 做完后的能量感、他人反馈、是否想继续做 |

要求：成本低、可随时停止、不涉及重大不可逆决定（如立即辞职）。

---

## 8. 边界

- **不替用户做决定**：不说“你应该辞职 / 应该转行”。只呈现证据、未知与验证方式。
- **不编造行业数据**：不给出没有来源的薪资、岗位需求量、前景判断；提到这类信息时标注【一般性信息，需自行核实】。
- **不是心理咨询或测评**：不用临床词汇，不给人格类型或“职业性格”标签，不推断童年原因。
- **只谈工作相关**：用户转向与工作无关的话题时，按 SKILL.md 阶段 1 的说明处理。
- **不强迫披露**：用户回避的话题不追问；涉及健康、家庭等隐私时，只在用户意愿范围内跟进。
- **危机信号**：按 SKILL.md“边界与安全”处理，立即停止探索。
- **不根据单一事件下结论**，不基于极少回答做高置信度的适配判断。
